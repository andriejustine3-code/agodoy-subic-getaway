EXCHANGE 5:
Fixing a logic bug

PROMPT:
what's wrong:

function prevImg(){
  let int = 1;
  let ctn = math.min(0, (int-1));
  heroImage.src = $("../slides/{ctn}.jpg");
}

function nextImg(){
  let int = 1;
  let ctn = math.min(4, (int+1));
  heroImage.src = $("../slides/{ctn}.jpg");
}

AI Response:
Almost every line has a bug:
function prevImg(){ 
  let int = 1; // resets to 1 every click, so never goes back
  let ctn = math.min(0, (int-1)); // 1. math -> Math  2. should be Math.max for min limit
  heroImage.src = $("../slides/{ctn}.jpg"); // 3. wrong string syntax
}
*Fixes:*

1.  `math.min` -> `Math.min` capital M
2.  For prev you want `Math.max`, not `min`. You want to stop at 0:
    `Math.max(0, int-1)` 
    For next you want `Math.min` to stop at 4:
    `Math.min(4, int+1)` — that part you had right
3.  String is wrong. It's not `$()` and `{}`. It's backticks + `${}`
    `"../slides/${ctn}.jpg"` -> `` `../slides/${ctn}.jpg` ``
4.  `let int = 1` inside function = resets every time. Put it outside.

Fixed:
let int = 1;
const heroImage = document.querySelector('.heroImage');

function prevImg(){
  int = Math.max(0, int - 1);
  heroImage.src = `../slides/${int}.jpg`;
}

function nextImg(){
  int = Math.min(4, int + 1);
  heroImage.src = `../slides/${int}.jpg`;
}
That will cycle 0-4 without going out of bounds.
